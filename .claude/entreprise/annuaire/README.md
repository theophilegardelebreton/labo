# Annuaire de l'entreprise

Chaque fichier est la fiche de poste d'un membre permanent. Elle décrit qui il est (rôle, regard, inspirations, compétences, manière de travailler), jamais un projet. Le Président recrée un directeur à partir de sa fiche à chaque nouveau projet : le membre garde son identité et repart d'une page blanche.

`type: directeur` signifie que le membre tourne dans sa propre session enfant, sous le Président. `type: membre` signifie qu'il travaille comme sous-agent dans l'équipe d'un directeur.

Une nouvelle fiche suit le même gabarit : en-tête (`id`, `nom`, `type`, `rattachement`, `embauche`), puis les sections Regard, Inspirations, Compétences, Méthode et Quand le convoquer.
