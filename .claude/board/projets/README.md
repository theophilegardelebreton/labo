# Projets du conseil

Un fichier par projet mené sur plusieurs séances : `<nom-court>.md`. Ces fichiers restent sur la branche de la session où le projet est mené et ne sont jamais fusionnés dans la branche par défaut. Ils servent à reprendre le projet dans cette même session, avec `/board reprendre <nom-court>`. Ce dossier ne contient donc normalement que ce README.

Structure d'un fichier projet :

```markdown
# <Nom du projet>

- Tableau : <URL de l'artifact>
- Phase : <phase en cours>
- État : en cours | en pause (en attente de : …)

## Objectif
## Ce qu'on sait déjà
## Décisions prises
- AAAA-MM-JJ · séance n · décision · vote
## Questions ouvertes
## Séances
1. <titre> · faite | en cours | prévue
## Équipe
- <Rôle> (<niveau>, modèle) : <regard>
```
