# Projets du conseil

Un fichier par projet mené sur plusieurs séances : `<nom-court>.md`. On reprend un projet avec `/board reprendre <nom-court>`.

Structure d'un fichier projet :

```markdown
# <Nom du projet>

- Tableau : <URL de l'artifact>
- Phase : <phase en cours>
- État : en cours | en pause (en attente de : …)

## Objectif
## Ce qu'on sait déjà
## Décisions prises
- AAAA-MM-JJ · séance n · décision · vote
## Questions ouvertes
## Séances
1. <titre> · faite | en cours | prévue
## Équipe
- <Rôle> (<niveau>, modèle) : <regard>
```
